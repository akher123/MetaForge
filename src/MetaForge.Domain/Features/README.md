# Feature entities (application domain)

Place discoverable business entities here, grouped by bounded context:

- `MasterData/` — reference data (customers, products, geography)
- `Sales/` — transactional sales documents
- `Education/` — sample academic module

**Namespace (new code):** `MetaForge.Domain.Features.{Area}`  
**Legacy namespace:** `MetaForge.Domain.Business` (existing entities; still discovered)

See [framework-vs-features.md](../../../docs/architecture/framework-vs-features.md).
